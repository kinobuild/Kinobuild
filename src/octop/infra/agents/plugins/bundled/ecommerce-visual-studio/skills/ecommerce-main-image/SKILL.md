# 电商主图

**你就做三件事：看懂图 → 写 prompt → 调 `generate_image`。** 就这样，不要加戏。

## 一、保真（唯一不能妥协的地方）

商品本体**不许改**：颜色、材质、纹理、形状、比例、结构、logo 与文字内容、配件数量。
背景 / 光线 / 道具 / 构图随你发挥。

prompt 里把不许变的**逐项列出来**（比"保持完全不变"有效得多）：

> 严格保持参考图中的手机壳不变：牛油果绿色、哑光硅胶质感、三摄镜头开孔的位置与大小、
> 闪光灯与激光雷达孔、侧边按键位置、包边弧度——**必须和参考图是同一只壳子**。

## 二、文案：写进 prompt，让模型画

**文案是画面的一部分，不是后期贴上去的贴纸。** 直接把中文写进 prompt，
让模型连同商品、背景、光线一起渲染——字和画面共用同一套光影，才像成品。

**卖点从图里推断，不要回头问用户。** 你能看见商品，就知道它的品类。
液态硅胶手机壳 → 亲肤、防摔、抗指纹；保温杯 → 保温时长、材质、容量。
用行业通识的卖点先做出来，交付时说明你用了哪些，**用户不满意再改字重出**（几秒钟的事）。

**两条底线**：不编功效数据（"1.5 米防摔"这种没有依据的不写）；
不用"新品上架""品质之选"这类废话占位——那不算卖点。

## 三、Prompt 模板（照这个写，出一张完整的电商主图）

一张合格的主图**不只是商品 + 一行字**，而是一套版式。照下面写：

```
商品主体：[保真声明，逐项列明不许变的特征]
场景与光线：[背景、光位、氛围、投影]
镜头：[焦段、景深、商品占画面比例、位置]

画面上方排版：
- 左上角圆角标签「新升级」，浅色底 + 深色字
- 主标题「液态硅胶手机壳」，超粗黑体，深色，两行
- 主标题下方副标题「柔滑亲肤 细腻手感」，小一号，浅灰

画面左侧三个图标 + 文字（图标为细线圆形图标）：
- 手形图标「液态硅胶 / 丝滑亲肤」
- 盾形图标「全包防摔 / 安心守护」
- 指纹图标「抗污防指纹 / 持久清爽」

画面底部一条浅色横条，三个图标 + 说明，等距排列：
- 「真机开模 / 精准贴合」「多色可选 / 时尚百搭」「环保材质 / 安全无害」

所有中文字必须清晰、笔画完整、无错字、无乱码，字体统一为无衬线黑体，排版整齐对齐。
不要水印、不要英文、不要多余文字。
```

**默认出 1 张**；用户说几张就几张。

## 四、尺寸

淘宝/天猫/京东/拼多多 **1:1，≥800px**（传 `size="1:1"`）。抖音可用 3:4。

## 五、交付

用工具返回的图交付，一句话说清：生成了几张、用了哪些卖点、什么规格。
提醒一句让用户核对商品细节即可。

## 其他技能

- 详情页长图 → `item-detail`
- 一张图裂变整套 → `fission-pattern`
- 亚马逊主图（**禁止文字**，与国内相反）→ `product-shots-main-image`
- 上架合规校验 → `platform-compliance`

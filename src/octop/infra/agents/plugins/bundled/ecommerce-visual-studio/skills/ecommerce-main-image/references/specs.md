# 平台规格与合规细节

> ⚠️ 各平台规则会变，且不同类目要求不同。**以下为常用起点，正式上架前请以平台最新规则为准。**
> 技能里给的数字是"够用且不容易出错"的保守值，不是平台承诺。

## 尺寸与比例

| 平台 | 常用主图 | 比例 | 备注 |
|---|---|---|---|
| 淘宝 / 天猫 | 800×800 起，常用 1000×1000 | 1:1 | ≥800 才支持放大镜 |
| 京东 | 800×800 起 | 1:1 | 主图多为白底 |
| 拼多多 | 800×800 | 1:1 | 首图白底更易过审 |
| 抖音商城 | 800×800 起 | 1:1 / 3:4 | 竖图在信息流占屏更大 |
| 亚马逊 | 2000×2000 | 1:1 | 主图要求纯白底 |
| 详情页长图 | 宽 750 或其倍数 | 竖长 | 逐屏切分 |
| 视频封面 | 1080×1440 | 3:4 | 竖版更占屏 |

**给 `generate_image` 传参**：`size="1:1"` / `"3:4"`，或直接给像素 `"1024x1024"`。
不确定就留空，由运行时选提供商兼容的默认值。

## 白底要求

- 亚马逊主图必须是 **纯白 RGB(255,255,255)**，商品占画面约 85%。
- 国内平台首图建议白底，但后续主图允许场景图。
- 出图后用工具量一下四角像素色值，不要靠肉眼判断"看着挺白"。

## 主图常见限制

- **牛皮癣**：主图不宜叠加大面积促销文字/边框，会影响点击与平台判定。
- **拼接**：多图拼接易被判违规，优先单场景单主体。
- **水印**：上架图不能带水印 → 出图时 `watermark=False`。
- **极限词**：最好 / 第一 / 最便宜 / 国家级 / 顶级 等一律不能用，
  包括画面里的文字和你的交付文案。
- **对比图**：贬低同行的对比图有法律风险。

## 需要人工复核的项（AI 出图特别容易错）

| 项 | 为什么容易错 |
|---|---|
| 商品颜色 | 模型会按"好看"调色，偏色即与实物不符 |
| Logo / 文字 | 文字生成不稳定，常出现错字、镜像、乱码 |
| 结构细节 | 镜头开孔、按键、接口位置可能被"美化"掉 |
| 配件数量 | 套装容易漏画件数 |
| 材质表现 | 哑光被画成亮面、硅胶被画成金属 |

**交付时必须提示用户复核这几项**。这不是免责声明，因为主图与实物不符
直接带来退货和差评——比"图不好看"的代价高得多。

## 底线

- 不生成他人品牌 logo、明星肖像、受版权保护的 IP 形象。
- 不把效果图当实拍宣传（尤其涉及防水、承重、续航等可验证功效）。
- 模特形象不得暗示为品牌代言人。
- 生成图**不能免检上架**。

# 电商详情页流水线

把「文案 + 视觉」串成一条可复用的产线：**一次收集信息 → 一次交付整套素材**。

## 何时使用

- 用户说"帮我做详情页 / 商品页 / listing + 配图"
- 用户给一个产品（名称、链接、或规格表），要一整套上架素材
- 用户已有 listing，要做优化版并重出图

## Step 0 — 先收集，缺什么直接问（不要编）

| 必须 | 说明 |
|---|---|
| 产品名 + 品类 | 决定关键词与合规红线 |
| 核心规格 | 尺寸/材质/容量/功率等硬参数 |
| 目标平台 + 站点 | Amazon US / 淘宝 / TikTok Shop / Shopee / 独立站…（决定尺寸、字数、禁词） |
| 目标人群 | 一句话即可 |
| 差异化卖点 | 没有就让用户给"和竞品比好在哪" |

| 可选（有则更好） | 说明 |
|---|---|
| 竞品链接 1~3 个 | 用于关键词缺口与卖点对比（不要用竞品名做图） |
| 品牌调性与视觉参考 | 颜色、风格词、参考图 |
| 价格带与促销政策 | 影响文案里的价格锚点表述（合规范围内） |
| 语言/本地化 | 英文、日文、小语种；决定文案语气 |

**缺失信息不要猜。** 把缺的项列成 3~5 条问题一次问完，再开工。

## Step 1 — 竞品与关键词

1. 读了竞品页的标题/五点/评价高频词（用户提供链接或截图时）
2. 拆出：`核心词 / 属性词 / 场景词 / 长尾词 / 负向词`
3. 产出关键词表（15~30 个），标注"已在竞品标题中/缺口"

> 若本 agent 装有 `ecommerce-product-selector` 技能，读它做选品与竞品打分；
> 没装也没关系 —— 按本节的关键词表方法直接做。

## Step 2 — 文案资产（分平台成稿）

按平台直接出成品，不要给模板让用户填：

- **标题**：平台字数上限内，主词前置，属性+场景+人群
- **五点/卖点**（Amazon bullet points、淘宝卖点、Shopify highlights）
- **详情描述**：结构为 场景痛点 → 解决方案 → 硬参数 → 使用场景 → 信任背书（**不编造认证/销量/评价**）
- **后台搜索词**（Amazon backend keywords）：不与标题重复、不堆砌竞品品牌名
- **促销/活动文案**（若给了政策）

> 本 agent 若装有 `ecommerce-detail-generation`（结构化 listing 写作）或
> `ecommerce-copywriting-generation`（中文爆款语气与促销文案），优先读它们；
> 没装则按本节结构自行成稿，不要因为缺技能就停下来问用户。

## Step 3 — 视觉脚本（每张图必须写满 7 项）

默认 **主图 1 张 + 详情图 6 张**，平台不同可增删：

| # | 用途 | 写清楚什么 |
|---|---|---|
| 1 | 主图 | 主体占比、纯色背景、是否要白底（Amazon 主图必须纯白） |
| 2 | 核心卖点图 | 一个卖点一张，配 ≤12 字短文案 |
| 3 | 场景图 | 真实使用场景，人物/环境描述（避免真人正脸特写） |
| 4 | 细节图 | 材质/做工/接口特写，微距景别 |
| 5 | 尺寸/容量图 | 标注线、参照物 |
| 6 | 对比图 | 与"上一代/通用款"对比（**不出现竞品品牌名与 logo**） |
| 7 | 包装/清单图 | 开箱内容平铺 |
| 8 | 信任背书图 | 认证/质保/售后（**只写真实具备的**） |

每张图输出这 7 个字段：

```
编号 / 用途：
画面主体：
构图与景别：
光线与背景：
图上文案（≤12 字，中英按站点）：
风格关键词（3~5 个）：
负向约束：不要水印、不要真人正脸、不要品牌 logo、不要长段文字
尺寸：<见平台规范>
```

## Step 4 — 出图

- 若当前 agent 具备生图能力（生图模型/生图专家），**直接按脚本逐张生成**，并在每次生成后回填"实际产出"对照表；
- 若没有生图能力，输出**可直接复制的提示词块**，让用户可以粘到任意生图模型；
- 图上的中文长文案不要交给生图模型渲染（容易写错字），改为"图 + 后期排版"的方案，并在交付里注明。

## 平台规范速查

| 平台 | 主图 | 详情/描述 | 硬性注意 |
|---|---|---|---|
| Amazon | 纯白背景、主体占比 ≥85%、无文字水印 | A+ 模块宽 970px；标题建议 ≤80 可见字符；五点每条 ≤500 字符 | 禁促销语/竞品名/绝对化用语/加边框 |
| 淘宝/天猫 | 800×800 或 1:1，≥5 张 | 详情页宽 750px | **广告法禁"最/第一/顶级/国家级"等极限词** |
| TikTok Shop | 9:16 竖版 1080×1920 | 前 3 秒必须给钩子 | 竖版构图，主体居中偏上 |
| Shopee / Lazada | 1:1 方图，≤9 张 | 短描述 + 属性表 | 首图纯品类展示 |
| Shopify / 独立站 | ≥2048px 方图 | 结构化段落 + ALT 文本 | 图片 SEO、加载体积 |

## Step 5 — 交付物（固定这四块）

1. **文案资产**：按站点分语言的标题/五点/描述/后台词
2. **图片任务表**：编号 | 用途 | 提示词 | 尺寸 | 负向词
3. **验收清单**：极限词检查、规格一致性、首图规则、尺寸与体积、是否有竞品痕迹
4. **待确认项**：本次缺的信息 + 需要用户拍板的取舍

## 硬规则（每次都遵守）

- **不编造**参数、认证、销量、评价、折扣力度；不确定就写"待确认"
- **不用绝对化用语**（最、第一、顶级、国家级、100%）——中国广告法风险；Amazon 同样禁止
- **不在图里出现竞品品牌/logo**，不做贬损性对比
- 图内文字尽量短；长文案用排版实现
- 交付前自查一遍"验收清单"，别把问题留给用户发现
- 用户只给了一个产品名时：先问齐 Step 0 的必填项，不要凭想象生成整页

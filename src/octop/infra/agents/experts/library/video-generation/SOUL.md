## 怎么把提示词变成片

### 1. 有参考图 / 首帧图的镜头 → 走图生视频

**这是保持多镜头一致性的主要手段。** 快图出的参考图作 `first_frame`：

```
first_frame: "generated/images/xxx.png"   ← 工作区相对路径
prompt:      [分镜给的运镜与动作描述]
```

**没有首帧图时**，把角色的完整外观描述**逐字重复**在 prompt 里（发色、服装、年龄、材质……），
不要写"同前一个镜头"——模型看不到上一个镜头。

### 2. 多镜头一致性：三条硬规则

```
① 同一角色跨镜头 → 复用同一张 first_frame，或逐字重复同一段角色描述
② 需要同一条片子风格统一 → 固定 seed，各镜头用同一个值
③ 分镜里已写明的运镜/景别/时长 → 原样传进去，不要自己改成默认值
```

**每个镜头出片后，检查角色外观是否和前一个镜头一致。** 不一致就换 seed 重出。

### 3. 抽卡：不满意就重出，但要算账

**视频是按时长计费的，比图像贵一个数量级。** 所以：

- 单镜头重出**最多 3 次**（含首次）
- 每次重出**换一个 seed**，不要盲目重复同一个
- 3 次都不行 → **停下来告诉用户**：哪个镜头卡住了、卡在哪（角色走形？运镜不对？），
  让他决定是改提示词还是接受当前效果

**不要闷头抽 10 次。** 那是烧钱，不是干活。

## 参数怎么填

```
duration       默认 5 秒。分镜写了时长就按分镜；没写且用户没要求就用默认，别自己拉长
aspect_ratio   竖屏短视频 9:16 / 横屏 16:9 / 方图场景 1:1 —— 按分镜或交付平台选
resolution     默认 720p。用户明确要高画质才升，升了要提一句成本
generate_audio 用户在 prompt 里要求了声音才开
seed           多镜头一致时固定同一个值；抽卡时每次换一个
watermark      false
```
